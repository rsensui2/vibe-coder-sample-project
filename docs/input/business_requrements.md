## 1. サービス概要

### 1.1 基本情報

| 項目 | 内容 |
|------|------|
| **サービス名** | DORONUMA（ドロヌマ） |
| **キャッチコピー** | 「最高の失敗は、最高の資産だ。」 |
| **サービス形態** | Web アプリケーション（モバイルファースト） |
| **対応プラットフォーム** | Web（PWA対応）、将来的にネイティブアプリ検討 |

### 1.2 サービスコンセプト

キラキラしたSNS文化へのアンチテーゼとして、**旅先や日常での「失敗」「トラブル」「修羅場」を共有し、笑いと共感に変換するプラットフォーム**。

ユーザーの精神的ダメージを「称号」と「コミュニティの温かみ」で浄化し、同時に他のユーザーへの**リアルな注意喚起・防犯情報**としても機能する。

### 1.3 ターゲットユーザー

| ペルソナ | 特徴 | ニーズ |
|----------|------|--------|
| **疲れたSNSユーザー** | 20〜40代、既存SNSのキラキラ投稿に辟易 | 本音で共感できる場が欲しい |
| **ネタ体質の旅行者** | 旅先でトラブルに遭いやすい | 災難を笑いに変えて昇華したい |
| **野次馬気質の閲覧者** | 他人の失敗談で酒が飲める | 読み物として面白いコンテンツが欲しい |
| **慎重な旅行計画者** | リアルな口コミ・注意情報を求める | 旅先の危険スポット情報が欲しい |

### 1.4 コアバリュー

1. **浄化（カタルシス）**: 失敗を投稿することで精神的ダメージを軽減
2. **共感（コミュニティ）**: 「災難だね」の一言で救われる温かみ
3. **防衛（インテリジェンス）**: 集合知による危険地帯の可視化
4. **報酬（ゲーミフィケーション）**: 失敗が称号・ポイントという資産に変わる

## 2. 機能要件（MVP）

### 2.1 ユーザー管理機能

#### 2.1.1 アカウント機能

| 機能 | 詳細 | 優先度 |
|------|------|--------|
| 会員登録 | メールアドレス / SNS連携（Google, X） | 必須 |
| ログイン・ログアウト | セッション管理、Remember Me | 必須 |
| プロフィール設定 | アバター、ニックネーム、自己紹介 | 必須 |
| 称号表示 | 現在の称号をプロフィールに表示 | 必須 |
| 退会 | アカウント削除、投稿の匿名化処理 | 必須 |

#### 2.1.2 ユーザーランク（称号システム）

失敗投稿の**質（評価数）**と**量（投稿数）**に応じて称号が付与される。

| ランク | 称号名 | 条件（案） |
|--------|--------|-----------|
| Lv.1 | 迷える子羊 | 初回投稿完了 |
| Lv.2 | 不運の旅人 | 投稿5件 or 災難だね100件獲得 |
| Lv.3 | 厄病神 | 投稿15件 or 災難だね500件獲得 |
| Lv.4 | 災厄の王 | 投稿30件 or 災難だね2000件獲得 |
| Lv.5 | ドロヌマ神 | 投稿50件 + ドロヌマ・アワード受賞 |

**特殊称号（バッジ）:**
- 🏥 **公認被災者**: 「不運の証明」を3回以上提出
- 🌍 **世界厄巡礼者**: 5カ国以上で失敗投稿
- 👑 **殿堂入り**: ドロヌマ・アワード月間大賞を受賞

### 2.2 投稿機能（ドロヌマ・ポスト）

#### 2.2.1 投稿作成

| 項目 | 詳細 | 必須/任意 |
|------|------|-----------|
| タイトル | 最大50文字 | 必須 |
| 本文 | 最大3000文字、マークダウン対応 | 必須 |
| カテゴリタグ | 下記から1つ以上選択 | 必須 |
| 絶望メーター | 1〜100%のスライダー | 必須 |
| 発生日 | 日付ピッカー | 必須 |
| 位置情報 | 地図から地点を選択 or 住所検索 | 任意 |
| 画像添付 | 最大5枚（各10MB以下） | 任意 |
| 不運の証明 | 証明書類の画像アップロード | 任意 |

#### 2.2.2 カテゴリタグ一覧

| タグ | アイコン | 説明 |
|------|----------|------|
| 💸 金銭 | 💸 | ぼったくり、詐欺、盗難など |
| 📦 紛失 | 📦 | パスポート、荷物、貴重品の紛失 |
| 🤢 体調 | 🤢 | 食中毒、怪我、病気 |
| 🚃 交通 | 🚃 | 遅延、欠航、乗り間違い、事故 |
| 😤 人間関係 | 😤 | トラブル、喧嘩、裏切り |
| 🏚️ 宿泊（廃墟） | 🏚️ | 写真詐欺、衛生問題、予約トラブル |
| 🌀 天災 | 🌀 | 自然災害、悪天候による被害 |
| ❓ その他 | ❓ | 上記に該当しないもの |

#### 2.2.3 絶望メーター

投稿者自身が「どれくらい絶望したか」を主観で評価。

| レベル | 範囲 | 表示 |
|--------|------|------|
| 軽傷 | 1〜25% | 😅 ちょっとした災難 |
| 中傷 | 26〜50% | 😰 結構キツかった |
| 重傷 | 51〜75% | 😱 マジで絶望した |
| 致命傷 | 76〜100% | 💀 人生終わったと思った |

#### 2.2.4 不運の証明（公認失敗マーク）

以下の証明書類をアップロードすると「✓ 公認失敗」バッジが付与される。

- 医療機関の診断書・領収書
- 警察の被害届・紛失届
- 交通機関の遅延証明書
- 保険会社への請求書類
- その他、第三者が発行した公的書類

> ⚠️ **個人情報保護**: アップロードされた証明書類は運営のみが確認し、公開されない。バッジ付与後は削除される。

### 2.3 評価・リアクション機能

#### 2.3.1 リアクションボタン

| ボタン | 表示名 | 説明 |
|--------|--------|------|
| 😢 | 災難だね | 共感・慰めの意を表す（いいねの代替） |
| 😂 | 笑った | 不謹慎ながら面白かった |
| 🙏 | 供養 | 投げ銭付きの最上級リアクション |

#### 2.3.2 供養（投げ銭）機能

| 項目 | 詳細 |
|------|------|
| 単位 | 1供養 = 100円相当 |
| 購入方法 | クレジットカード、コンビニ決済 |
| 還元 | Amazonギフト券、PayPay残高等に交換可能 |
| 手数料 | 換金時に20%を運営が徴収 |
| 最低換金額 | 500円分（5供養）から |

#### 2.3.3 コメント機能

- 投稿へのコメント（ネスト2階層まで）
- コメントへのリアクション（災難だね、笑った）
- 投稿者によるコメント固定機能
- 通報機能

### 2.4 ドロヌマ・アワード

#### 2.4.1 選出基準

| アワード | 期間 | 選出基準 |
|----------|------|----------|
| 週間ドロヌマ賞 | 毎週日曜締切 | 災難だね数 × 絶望メーター で算出 |
| 月間ドロヌマ大賞 | 毎月末締切 | 週間賞受賞者の中から運営が選出 |
| 年間グランプリ | 年末 | 月間大賞受賞者の中からユーザー投票 |

#### 2.4.2 受賞特典

- プロフィールに受賞バッジ表示
- 賞金（供養ポイント）
  - 週間賞: 10供養（1,000円相当）
  - 月間大賞: 50供養（5,000円相当）
  - 年間グランプリ: 300供養（30,000円相当）

## 3. 非機能要件

### 3.1 パフォーマンス

| 項目 | 目標値 |
|------|--------|
| ページ読み込み時間 | 3秒以内（LTE環境） |
| API応答時間 | 200ms以内（95パーセンタイル） |
| 同時接続数 | 10,000ユーザー |
| 画像アップロード | 10MB/枚、5枚まで |

### 3.2 セキュリティ

| 項目 | 対応 |
|------|------|
| 認証 | JWT + リフレッシュトークン |
| 通信 | HTTPS必須 |
| 個人情報 | 証明書類は確認後即削除 |
| 不正投稿 | AI + 人力でのモデレーション |
| レート制限 | 投稿: 10件/日、リアクション: 100件/時 |

### 3.3 可用性

| 項目 | 目標 |
|------|------|
| 稼働率 | 99.5%（月間ダウンタイム3.6時間以内） |
| バックアップ | 日次自動バックアップ |
| 障害復旧 | RTO 4時間、RPO 24時間 |

### 3.4 スケーラビリティ

- コンテナベースのデプロイでオートスケール対応
- CDNによる静的アセット・画像配信
- データベースのリードレプリカ構成

## 4. UI/UX設計方針

### 4.1 ビジュアルデザイン

| 要素 | 方針 |
|------|------|
| **カラースキーム** | ダークモード基調 |
| **メインカラー** | 泥をイメージしたブラウン系 (`#3D2B1F`, `#5C4033`) |
| **アクセントカラー** | くすんだ警告イエロー (`#C9A227`) |
| **背景** | 深いグレー (`#1A1A1A`, `#2D2D2D`) |
| **フォント** | 本文: Noto Sans JP / 見出し: 太めのゴシック |

### 4.2 コミュニティトーン

独自の用語・言い回しでコミュニティ感を醸成:

| 標準的な表現 | DORONUMA用語 |
|--------------|--------------|
| ようこそ | 入沼おめでとうございます |
| 投稿する | 沼に落とす |
| いいね | 災難だね |
| フォロー | 同行する |
| 人気投稿 | 底なし沼 |
| ログアウト | 一時浮上 |
| 退会 | 成仏する |

### 4.3 UXの工夫

- **投稿のハードルを下げる**: テンプレート機能（「〇〇でぼったくられた」等）
- **ネガティブを楽しく**: アニメーションやサウンドで「災難だね」の体験を演出
- **読み応え重視**: 長文投稿を読みやすくする組版
- **PWA対応**: オフラインでも過去投稿を閲覧可能
